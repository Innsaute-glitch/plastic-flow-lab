# Open questions

The question box from `CLAUDE.md`: an agent that hits an ambiguity writes it here and stops instead of guessing. The orchestrator answers below the question, then removes the entry once the answer is in the code or docs.

Format:

```
## <ticket or file> (<date>)
Question: ...
Where: ...
Options I see: (a) ... (b) ...
Answered by orchestrator: ...
```
